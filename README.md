# 🌿 متجر كنوز مكة | Kunooz Makkah
> المتجر المتخصص في الزيوت والتركيبات الطبيعية المعصورة على البارد لعلاج جميع مشاكل الشعر.

---

## 🌟 مميزات المشروع
- **واجهة مستخدم عصرية (Storefront):** متوافقة مع جميع الأجهزة والهواتف بتصميم أنيق (Tailwind CSS) وخط Cairo ودعم كامل للغة العربية (RTL).
- **قاعدة بيانات سحابية (Firebase Realtime Database):** مزامنة فورية في الوقت الفعلي للمنتجات والطلبات بين لوحة الإدارة والمتجر.
- **لوحة تحكم وإدارة كاملة (Admin Dashboard):** 
  - إضافة، تعديل، وحذف المنتجات الحقيقية.
  - إمكانية رفع صور المنتجات مباشرة من الجهاز مع معاينة فورية.
  - إدارة ومتابعة الطلبات الواردة وتحديث حالاتها (جديد، تم التأكيد، تم الشحن، مكتمل).
- **تكامل مباشر مع الواتساب (WhatsApp Direct Order):**
  - إرسال تفاصيل الفاتورة كاملة والمنتجات والعنوان فور إتمام الطلب إلى الواتساب: `+20 10 80369841`.
  - زر عائم للتواصل والاستشارة السريعة مع العملاء.
  - زر محادثة العميل بنقرة واحدة من لوحة الإدارة.
- **نظام سلة المشتريات والمفضلة:** يعمل بسلاسة ويدعم كوبونات الخصم (`MAKKAH20`).

---

## 📂 هيكل ملفات المشروع
- `index.html`: واجهة المتجر الرئيسية للزبائن.
- `admin.html`: لوحة الإدارة والتحكم لإضافة المنتجات ومتابعة الطلبات.
- `app.js`: منطق المتجر، السلة، المعاينة السريعة، وربط الواتساب.
- `admin.js`: منطق لوحة الإدارة، العمليات (CRUD)، والتحكم بالطلبات.
- `firebase-config.js`: إعدادات وربط Firebase Realtime Database.
- `style.css`: التنسيقات الإضافية وتأثيرات الحركة.

---

## 🚀 التشغيل المباشر
يمكن فتح `index.html` أو `admin.html` مباشرة في أي متصفح دون الحاجة لأي خادم محلي.
